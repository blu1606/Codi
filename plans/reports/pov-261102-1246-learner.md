## Decisions with evidence

- **Guest "Mua ngay" gate.** Keep the account requirement for purchase, because ownership is tied to an account and guest enrolment would need a different data model. Baymard supports making the registration path prominent, so the gate now shows it as a visible secondary action (#11). A fuller change (cart before login, account created on the confirmation step, per Baymard's delayed-account article) is a product decision and is not implemented.
- **Repeated GitHub card.** Removed from the dashboard (#10). The optional step stays in onboarding and profile. The NN/g and Duolingo evidence both argue against repeating an optional prompt.
- **Onboarding length.** Kept (goal, level, time, mode, 10-question entry test). Each step has Back and Bỏ qua, and the learner can start from lesson 1 without the test. That matches the skippable pattern in the sources, so no merge was made.
- **Course detail purchase.** Kept "Mua ngay" as the one filled primary, with "Thêm vào giỏ" as the secondary. This matches the Coursera single-primary pattern closely enough that the change was not worth the churn.
- **Dashboard order.** Already starts with the "Tiếp tục học" next-step card after the greeting. No reorder needed.
