Props là gì?

Props (properties) là cách component cha truyền dữ liệu xuống component con. Props chỉ đọc: component con không được tự sửa props của mình.

function Greeting({ name }) { return <h1>Xin chào, {name}!</h1>; }

Props khác state thế nào?
